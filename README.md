# Zuzuki Cafe website (demo)

A fast, single-file cafe website: menu with build-your-order, WhatsApp ordering and booking, gallery, Hindi/English switch.

## Customise for a client
Open `index.html` and edit:
1. `var CFG={...}`: name, WhatsApp number (country code, no `+`), hours text, address, phone, email, Instagram handle.
2. `CFG.hours`, `CFG.open`, `CFG.close`: shown hours and the "Open now" badge (24h time).
3. `var PR={...}`: dish prices (sample prices are in place).
4. Replace the `[PLACEHOLDER]` texts (offer, reviews, story, years).

## Deploy on GitHub Pages
Settings > Pages > Deploy from a branch > `main` / `(root)`.
